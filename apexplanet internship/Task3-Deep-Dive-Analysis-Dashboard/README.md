
# Netflix Deep-Dive Analysis & Interactive Dashboard
## ApexPlanet Data Analytics Internship - Task 3
### Project Overview
This project focuses on deep-dive analysis and interactive dashboard development using the Netflix Movies and TV Shows dataset. The dashboard was developed using Power BI to analyze content distribution, audience ratings, countries, and release trends.
---
## Objectives
* Perform deep-dive analysis of Netflix content.
* Create interactive visualizations.
* Define key performance indicators (KPIs).
* Generate business insights using Power BI.
---
## Key Performance Indicators (KPIs)
| KPI                    | Value         |
| ---------------------- | ------------- |
| Total Titles           | 8809          |
| Movies                 | 6131          |
| TV Shows               | 2676          |
| Top Country            | United States |
| Peak Production Period | 2019-2020     |
---
## Dashboard Features
* Total Titles KPI
* Movies vs TV Shows Analysis
* Top Countries Analysis
* Rating Distribution Analysis
* Release Year Trend Analysis
---
## Key Insights

* Movies dominate Netflix content.
* United States is the largest content producer.
* TV-MA is the most common rating.
* Netflix content production peaked between 2019 and 2020.
* India is the second-largest content producer.
